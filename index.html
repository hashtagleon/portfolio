02 / Principles

05 rules

Built the careful way.

01

Readable before clever

Code is read far more often than it is written. Plain names and short functions win over tricks.

02

Start from the structure

Decide where data lives and how parts talk to each other before writing screens.

03

Ship small, ship often

A working version in people's hands teaches more than a perfect plan.

04

Respect the user's device

Ask for the fewest permissions. Keep battery, memory, and privacy costs low.

05

Keep learning in public

Write down what broke and why. Share the code when it helps someone else.
